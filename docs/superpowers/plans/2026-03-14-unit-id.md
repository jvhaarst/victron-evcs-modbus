# Unit ID CLI Argument Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Modbus unit/slave ID configurable via `--unit-id` (default 1) instead of hardcoding `device_id=1` everywhere.

**Architecture:** Add `unit_id: int = 1` parameter to `read_registers()` and `write_register()` in `cli.py`; add `--unit-id` argparse argument; thread unit_id through all call sites including `_handle_write()`, `main()`, and `RegisterEditorApp` in `tui.py`.

**Tech Stack:** Python 3.12, pymodbus, Textual, pytest

---

    mock_client = MagicMock()
    mock_client.connect.return_value = True

    def mock_read(address, count, device_id):
        response = MagicMock()
        response.isError.return_value = False

    monkeypatch.setattr(sys, "argv", ["cli.py", "127.0.0.1", "--unit-id", "3"])
